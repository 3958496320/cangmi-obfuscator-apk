如何选择文件管理器？

如果你的手机装了多个文件管理器（如 MT管理器、ES文件浏览器、手机自带管理器），点击上传按钮时 Android 会弹出选择菜单。

方法 1：切换上传模式
下方有 4 个小按钮（限定类型 / 通用模式 / 文本模式 / 不限类型），不同模式会触发不同的选择器。如果当前模式没出现选择菜单，换一个模式再点上传按钮试试。
方法 2：清除默认管理器
如果点击上传按钮总是直接打开某一个管理器（没有选择菜单），说明你之前选过"始终"。

操作步骤：
  • 打开手机「设置」→「应用管理」
  • 找到当前默认的文件管理器（如 MT管理器）
  • 点「默认打开」/「打开方式」
  • 点「清除默认设置」
清除后再点上传按钮，就会重新弹出选择菜单。
方法 3：MT管理器直接打开
打开 MT管理器 → 找到 .lua/.txt 文件 → 长按 → 「打开方式」→ 选「文本」→ 复制内容 → 回到本页粘贴。

提示：浏览器无法直接调用某个特定 App，必须通过系统的文件选择器。Android 系统决定显示哪些管理器。
