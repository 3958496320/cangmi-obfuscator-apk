【两种使用方式】

------------------------------------------------------------
方式 A：直接运行（需要已安装 Python）
------------------------------------------------------------
  1. 双击  启动.bat   (或 run.bat)
  2. 弹出图形界面，开始使用

------------------------------------------------------------
方式 B：打包成 EXE（推荐，打包后无需 Python）
------------------------------------------------------------
  1. 双击  build_exe.bat
     (会自动安装 PyInstaller，约 1-3 分钟)
  2. 打包完成后，在  dist\  文件夹里会生成：
       CangMiObfuscator.exe
  3. 把这个 exe 复制到任何地方，双击即可运行
     (无需安装 Python，可发给别人用)

------------------------------------------------------------

【文件说明】

  build_exe.bat     -> 打包成 EXE 的脚本（方式 B 用这个）
  启动.bat / run.bat -> 直接运行（方式 A 用这个）
  build_exe.py      -> 打包脚本（被 build_exe.bat 调用）
  src\              -> 源代码目录
  examples\         -> 示例（混淆前后对比）
  tests\            -> 测试文件
  README.md         -> 详细技术文档

【常见问题】

Q: 双击 build_exe.bat 没反应？
A: 检查是否已安装 Python。打开 cmd 输入 python --version
   若提示"不是内部命令"，说明 Python 未加入 PATH，
   重新安装 Python 时勾选 "Add Python to PATH"

Q: 打包失败？
A: 手动执行：
   pip install pyinstaller
   python build_exe.py

Q: exe 太大？
A: 正常现象，PyInstaller 会打包 Python 运行时，
   单文件 exe 约 30-50MB 属正常。
